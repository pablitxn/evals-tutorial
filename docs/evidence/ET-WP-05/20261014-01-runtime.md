## Provider, review and telemetry boundaries

Global explicit env is TUTORIAL_PROVIDER=openai|azure_foundry, TUTORIAL_MODEL,
TUTORIAL_API_KEY, plus Azure's resource endpoint/API version. Routing and key are
passed explicitly for every role; no fallback, per-role model, tools or automatic
retry exists. Direct OpenAI uses a fixed api.openai.com base URL. The Azure path
initially accepts HTTPS *.openai.azure.com resource roots with key auth and an
explicit API version; project, v1, sovereign or alternate endpoint kinds are
unsupported rather than guessed. Config revision hashes only non-secret routing
fields; key rotation does not change it. Status receives only ProviderSummary.
Python has a minimal explicit environment, with no worker/frontend key exposure,
inherited .env, Docker socket, HOME or arbitrary provider env. Raw SDK diagnostics
are bounded and discarded by the supervisor, and failures expose generic typed
messages. A missing prepared interpreter/SDK cannot produce successful inference.

Judge accepts only rubric and known criterion IDs. Code disables judge calls;
Mixed/LLM Judge have at most two lifetime calls per run/example, including failed
attempts, at most 2048 output tokens per call and a 60-second provider duration.
Rebinding cannot replenish a budget or change a row. Combined judge/review
concurrency is at most two; lifetime binding/review maps are capped at 10000.
Host deadlines and AbortSignals reject even an injected transport that ignores
cancellation; production kills the supervised process. Cancellation requests do
not promise that remote inference stopped or that billing was refunded.

Review uses one attempt per review ID, the same global model and bounded tokens/
deadline. Source is quoted data; no import, execution, tools, browser or separate
evaluation is possible. WP09 supplies its grounded prompt, immutable evidence
derivation and quotation validator through this transport. Operational errors
never become ready/failing evaluation scores. Explicit retries need a new ID.

The optional telemetry endpoint must be trusted loopback /v1/traces. Pass WP07's
one sourceProjectName as telemetry.projectName; it becomes
openinference.project.name for Python/MAF spans. Python extracts W3C
traceparent/tracestate, creates an agent root and returns AgentSuccess.traceId.
AgentService preserves that field. WP06 must retain it as RowResult.phoenix.traceId
for WP07's correlated readback. No separate invented Phoenix URL is returned.
Sensitive telemetry is disabled and export flushing is bounded. Absence of an
exporter is not claimed as recorded Phoenix telemetry.
